# منصة إبداع الوزية

الموقع الرسمي للنشاط الطلابي في **متوسطة الوزية**، مجاني بالكامل ويعمل على أي جوال أو لابتوب.

- مسؤولة النشاط الطلابي: نورة المصلح
- مديرة المدرسة: خزماء القحطاني

**كيف يعمل مجاناً؟**
- صفحات الموقع على **GitHub Pages**: مجانية، لا تتوقف، ورابطها ثابت.
- البيانات والصور وتسجيل الدخول على **Supabase**: مجاني حتى 1 جيجابايت للصور، والحد الأقصى للملف الواحد 50 ميجابايت.
- الصور تُضغط تلقائياً قبل الرفع، فتكفي المساحة لآلاف الصور.
- مهمة تلقائية تزور قاعدة البيانات كل يومين حتى لا يوقفها Supabase بسبب عدم النشاط.

---

## الإعداد لأول مرة (مرة واحدة فقط، حوالي 15 دقيقة)

### 1) قاعدة البيانات في Supabase
1. ادخلي على supabase.com ← **Start your project** ← سجّلي بحساب GitHub.
2. **New project**، الاسم: `ibdaa-alwazia`، والمنطقة الأقرب (مثل Frankfurt). احفظي كلمة مرور قاعدة البيانات في مكان آمن.
3. من القائمة الجانبية **Authentication ← Users ← Add user ← Create new user**:
   - البريد: بريد مسؤولة النشاط
   - كلمة مرور قوية
   - فعّلي **Auto Confirm User**
4. افتحي **SQL Editor ← New query**، والصقي محتوى الملف `supabase/schema.sql` كاملاً.
5. في آخر سطر من الملف استبدلي `ADMIN_EMAIL_HERE` ببريد المسؤولة نفسه، ثم اضغطي **Run**.
6. افتحي **Project Settings ← API** وانسخي قيمتين: **Project URL** و **anon public key**.

### 2) ربط الموقع بقاعدة البيانات
افتحي الملف `docs/config.js` وضعي القيمتين بدلاً من `YOUR_SUPABASE_URL` و `YOUR_SUPABASE_ANON_KEY`.

### 3) نشر الموقع على GitHub Pages
1. على github.com أنشئي مستودعاً جديداً (New repository) باسم `ibdaa` واجعليه **Public**.
2. ارفعي كل ملفات المشروع إليه (Add file ← Upload files ← اسحبي المجلدات).
3. **Settings ← Pages**: اختاري Branch: `main` والمجلد `/docs` ← **Save**.
4. بعد دقيقة يصبح الموقع متاحاً على: `https://اسم-حسابك.github.io/ibdaa/`
5. **Actions**: إن ظهر زر تفعيل الـ workflows اضغطيه (لتعمل مهمة إبقاء قاعدة البيانات نشطة).

### 4) آخر خطوة في Supabase
**Authentication ← URL Configuration**: ضعي رابط الموقع في **Site URL**، وأضيفي `رابط-الموقع/login.html` في **Redirect URLs** (لكي يعمل «نسيتِ كلمة المرور؟»).

## الاستخدام اليومي
- **لوحة التحكم:** `رابط-الموقع/admin.html` (يوجد أيضاً رابط «دخول الإدارة» أسفل كل صفحة).
- **أول دخول:** تقترح لوحة التحكم إضافة بيانات تجريبية لاستعراض شكل المنصة. كل عنصر منها يحمل علامة «تجريبي»، وتحذفينها كلها بزر واحد من **نظرة عامة** أو **الإعدادات**.
- **إضافة مسابقة أو إنجاز أو غيرهما:** اختاري القسم ← **إضافة** ← املئي البيانات ← اسحبي الصور ← **نشر**. يظهر فوراً في الموقع.
- **إخفاء عنصر دون حذفه:** أيقونة العين. **تمييزه في الصفحة الرئيسية:** أيقونة النجمة.
- **رسائل أولياء الأمور:** قسم «الرسائل والاستفسارات».
- **نسيتِ كلمة المرور؟** اكتبي بريدك في صفحة الدخول ثم اضغطي «نسيتِ كلمة المرور؟»، وسيصلك رابط على البريد.

## الحماية
- صلاحيات قاعدة البيانات (Row Level Security): الزوار يقرؤون المحتوى الظاهر فقط ويرسلون رسائل التواصل فقط. لا يستطيع أي حساب آخر غير بريد المسؤولة المسجَّل التعديل أو رفع الملفات أو قراءة الرسائل، حتى لو أنشأ حساباً.
- مفتاح `anon` في `config.js` عام بطبيعته، وهذا تصميم Supabase المعتمد. لا تضعي أبداً مفتاح `service_role` في الموقع.
- نموذج التواصل محمي من الرسائل الآلية، وبحد أقصى 20 رسالة كل 10 دقائق.

## ملفات المشروع
```
docs/                 الموقع كاملاً (الصفحات، لوحة التحكم admin.html، الأصول)
docs/config.js        بيانات الربط مع Supabase
supabase/schema.sql   إنشاء قاعدة البيانات والصلاحيات والتخزين
.github/workflows/    مهمة إبقاء قاعدة البيانات نشطة
```
